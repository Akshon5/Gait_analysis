# Human Gait Analysis Using Computer Vision

This documentation presents the development of a classical computer vision–based system for human gait analysis in rehabilitation contexts.

The project explores structured video preprocessing, silhouette extraction, and motion analysis techniques to transform walking patterns into quantifiable metrics.

## Pipeline Overview

The system follows a structured pipeline:

1. Video input  
2. Frame extraction and preprocessing  
3. Foreground extraction (silhouette generation)  
4. Motion representation  
5. Gait cycle analysis  

---

## Objective

The goal of this project is to build a lightweight and interpretable gait analysis system using classical computer vision techniques, without relying on complex deep learning models.

---

## Key Idea

Instead of using heavy models, this system focuses on:
- Motion-based analysis  
- Signal-based interpretation of movement  
- Clear and explainable outputs  

---

## Final Insight

By progressively refining raw video data into structured motion signals, the system demonstrates how simple computer vision techniques can effectively capture and analyze human gait patterns.
